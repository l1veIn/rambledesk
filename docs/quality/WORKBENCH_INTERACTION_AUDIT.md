## 对照方法

对照同类项目的官方文档和公开实现，再用 RambleDesk 的生产组件、测试与浏览器夹具确认具体问题。没有安装或完整实测竞品，不据此给产品成熟度排名。

| 工作台 | 对照项目与可借鉴的原则 | 本轮取舍 |
| --- | --- | --- |
| 自由反馈 | [MCP Feedback Enhanced](https://github.com/Minidoracat/mcp-feedback-enhanced)：反馈编辑器提供 Ctrl/⌘+Enter 提交。 | 增加正文内快捷提交，复用已有提交入口及门禁。现有附件、图片粘贴、草稿保存不重复建设。 |
| 文稿审阅 | [Plannotator 的选文批注实现](https://github.com/backnotprop/plannotator/blob/main/packages/ui/hooks/useAnnotationHighlighter.ts)：展示的文字范围与实际批注目标一致。 | 修正继续已有批注时的作用范围提示，保留每段一条、原位编辑及历史多条恢复，不增加独立批注面板。 |
| 网页评审 | [Agentation 的快捷键与输入保护](https://www.agentation.com/features)：Escape 取消操作，输入时保留页面自身的键盘行为。 | 同步退出元素选择，保留未完成批注；清除已经失效的定位错误。保留固定批注框及网页视口。 |

以上只借鉴交互原则，没有引入竞品代码或新增第三方依赖。

## 已实现

- 自由反馈正文支持 Ctrl/⌘+Enter，按钮 tooltip 展示快捷键。空白、锁定、附件处理中、提交和整理过程中不触发提交；普通 Enter、Shift+Enter 与输入法行为保留。其他工作台不注册此快捷键。沿用现有保存、语音收尾、Cooking 和发布流程。
- 文稿同段已有批注 A，再选 B 时，工具栏显示 A 的原引用或“整段”，操作明确为继续批注、为原批注添加建议或继续建议改写。原锚点、正文、旧建议措辞（含表示删除的空串）以及历史多条批注的选择规则保持不变。
- 网页选择模式中的 Escape 返回浏览、收起批注框，只清理临时选择。网页输入框、可编辑内容、输入法和已被页面处理的 Escape 保留原行为。切换批注、刷新时清除旧的元素定位错误，新失败仍显示。iframe 桥接继续校验来源、origin、协议、channel、就绪状态和当前模式；网页自行部署的桥接脚本需更新才能发送取消事件。
- 输入法判断函数原样移到公共层，原 Agent 输入框模块保留兼容导出。未放宽模块依赖检查。

交互合同说明同步到[文稿审阅](../workbench/document-review.md)与[网页评审](../workbench/web-review.md)。

## 留待单独判断

文稿“原稿可用”可与删除段落或改写建议同时存在。目前数据不会丢失，但整稿结论可能与局部意见矛盾。可考虑就地提醒并让人调整结论；本轮没有自动改动人的判断或增加提交限制。

版本比较、动画暂停、区域或多元素批注属于更大的工作流改动，应以具体任务验证收益，不能仅因同类项目提供便加入。

## 同日后续：改为 Markdown 文档审阅

用户确认将 `document_review` v1 直接改为完整 Markdown 输入，无旧请求迁移。此演进替代上文的“一段一条”和段内锚点交互：支持同段多条、跨段和全文批注，锚点使用全篇原始 Markdown 的 Unicode 标量半开区间及精确引用，取消段落删除标记，以空替换建议表达删除。原稿保持只读，反馈仍由 Agent 在提交后处理。

### 已知性能边界

接近 120000 标量、包含大量短 emphasis 的极端输入，首次同步解析实测约 6.35 秒，期间可能阻塞界面。超过 10000 个 AST 节点时，当前实现回退为单叶原始 Markdown，保留精确选文和批注能力，不承诺该极端文档仍完整格式化展示。

列表压力用例隔离运行约 315 毫秒；首次并行执行曾发生 OOM，确切原因未确定，保留该失败记录，不据隔离成功推断所有并发或设备条件已经通过。性能数据是本机特定输入的观察，不是通用耗时保证。

## 同日后续：在阅读位置完成局部批注

本阶段继续调整 Markdown 审阅交互：选文后在原文附近填写意见，完成局部编辑后继续阅读，最后统一提交整份反馈。选区入口收敛为批注和建议修改；删除在建议编辑卡内通过空替换文本表达，不再单列为选区入口。修改建议的理由可以留空，普通批注提交时仍须填写意见；两种批注的 `body` 字符串字段都不能省略。原文、精确标量锚点、多条批注和整稿判断合同不变。

局部“完成”和 Ctrl/Cmd+Enter 只在当前批注有效时结束编辑；Escape 保留输入，包括尚未填写的普通批注。刚创建且未改动的新建议例外：仍为预填原文且没有理由时不能直接完成，Escape 或收起会移除它，避免留下无修改的占位建议；已有或已修改的建议保留。前端完成与整轮提交也检查替换文本等于原文且没有理由的情况，提示补充实际意见。两者都不提交整轮，也不作为保存成功的回执。输入法组合不被快捷键接管。局部卡片在宽屏位于原文旁、窄屏通常位于对应内容块后；长块的选区远离块底时，在锚点下方显示限高浮卡，保留共享语音和附件能力。
