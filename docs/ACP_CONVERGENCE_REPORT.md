## 体验与性能改动

| 问题 | 本轮结果 | 已验证的边界 |
| --- | --- | --- |
| 100 条活动可能只覆盖最后一个 turn | 默认展示最近 20 轮；首份快照不足 20 轮时，额外预取一次按 20 轮边界划分的历史；上滑跨过顶部 240px 自动补页 | 历史与实时窗口合并，读取总量不等于恰好 20 轮；不在初始短列表上自动抽干历史，保留锚点和重试入口 |
| 简单放大实时窗口会放大每次刷新 | 实时仍取 100 条；历史查询最多 1,000 条、约 2 MiB，先读长度再读选中的完整内容 | 极端长 turn 跨页并明确提示；单条超预算记录允许独占一页，确保游标继续推进 |
| 历史越多，重建和渲染越重 | 复用未变化活动/轮次、线性合并分页；有最终回答的完成 turn 默认折叠过程，保留用户展开选择 | 运行、无最终回答的中断轮次及手动展开的过程默认最近 60 条，每次再显示 60 条；答案、错误、权限保持可见 |
| 工具超过实时 100 条窗口后仍可能更新 | turn 结束时定向补齐已加载的旧工具记录 | 迟到快照、分页和完成响应不覆盖更新内容；失败显式重试，不循环拉取 |
| 打开草稿被安装检测拖住 | 已保存配置先展示和预连接；检测最多并发 3 个，渐进更新并复用当前控制器的结果 | 关闭/转正后不继续派发检测批次，迟到结果不能覆盖用户的新选择 |
| Agent 标识和附件入口不一致 | 复用适配器原有 SVG logo；移除 Agent 附件输入，集中到 Ramble 请求 | 保留富内容历史与底层 typed prompt 接口；纯文本粘贴、IME、撤销和草稿恢复继续工作 |
| 一个会话操作触发整个工作台刷新 | 连接与配置事件按资源发送，发送/结束/停止时只另更新导航 | 其他会话和设置不再接收无关失效；停止连接仍更新侧栏时间 |
| 完成后仍持有流式内容缓存 | 完成或退出实例时释放最后文本和工具 map 容量，SQLite 保留历史 | 保留 turn/instance 身份，用于恢复和迟到事件归属 |

这些是查询数量、挂载数量和刷新范围的可核对变化。本轮没有同机前后 CPU、RSS 或交互延迟基准，不给出未经测量的速度/内存百分比。

## 删除与抽象取舍

- 删除本分支尚未发布、生产启动已不使用的 Pi wrapper/托管扩展和 `managed-mcp-stdio` 转发入口，以及只验证这些旧入口的测试、夹具、feature 和依赖。所有 Agent 的托管反馈继续走已有通用命令。
- 删除旧新建表单、内嵌反馈续接状态、Agent 附件处理、无生产调用的引用搜索/写入 API 和孤立文案。保留实际使用的引用读取、历史富内容、安全 Markdown 与工具展示。
- 将历史滚动和分页呈现集中到 `SessionTranscript`，共享已有图标资源；ACP 集成测试只抽取重复的临时数据库、Node 夹具和等待 helper。
- 合并普通/类型化输入和 prepared 首发共用的活动构造；保留首发转正的事务、发送前持久化、会话级互斥和迟到响应保护，不为了减少行数合并业务上不同的状态。
- 保留 HTTP/Tauri 共享 application 合同、会话 scope/撤销/投递恢复层和外部 MCP/Pi/dsh 接入。它们承担不同的归属、授权及恢复责任，进一步套通用宏会隐藏这些边界。

## Codeg 参考与保留项

参考本地 Codeg `3ebdfed1d7c0b71d71880a3d2e0f8e09545feae1` 的 turn 窗口、顶部自动分页和连接生命周期；来源记录见 [CODEG_PORTS.md](CODEG_PORTS.md)。没有搬入其完整虚拟列表或连接框架。

当前连接仍是按需建立：打开正式 Agent tab 或准备草稿时连接；已有连接复用，不会在启动时遍历所有历史会话。关闭正式 tab 只关闭视图。Codeg 的空闲回收具有 tab、运行、权限和后台任务保护；RambleDesk 的 ACP EndTurn 后还可能等待 Ramble 反馈，不能据此直接回收连接。

后续值得做、但本轮没有假装完成的三项：

1. **正式连接空闲回收**：先建立反馈创建/等待/投递的保活约定和竞争保护，再验证原 remote ID 的恢复能力。当前 disconnected 的投递 worker 不主动启动 Agent，简单照搬超时会破坏续接。
2. **进一步统一 scope 实现**：通用命令已复用现存的 managed HTTP scope 层；若移除内部 MCP 形态，应先把撤销、排空和隔离证据迁移到 JSON 入口，再删除重复实现。
3. **整个应用包体与超大历史内存**：Web App chunk 仍约 1.53 MB（gzip 443 KB），构建有既有的大 chunk 提示；用户持续主动展开或加载时内容仍会累积。是否增加模块拆包、内存窗口或虚拟列表，应基于实际 profiling，而不是默认增加框架。
