# 工作台首次使用引导

自由反馈、文稿审阅、网页评审、终端试用、视觉反馈和差异评审提供 Rambelle 分步引导。遮罩覆盖当前屏幕，逐步突出真实界面的对应区域，说明它的用途和下一步操作。引导只解释现有能力，不创建示例标注或批注、改变原稿或草稿，也不启动终端、执行命令、录音、删除段落或提交反馈。

## 出现与重看

已配置引导的类型在业务视图加载完成、当前客户端首次进入可编辑状态时自动出现一次。六种类型分别记录，引导完成或跳过后不再自动打断后续请求；标题栏的使用引导（Show guide）入口可以随时重新查看。按操作复杂度编写引导，简单问答和排序不增加引导；其他类型不自动生成引导。

加载中、只读、已结束、录音、语音整理和操作锁定期间不自动展开。如果首次进入时已有其他模态框，引导会等它关闭后再出现。切换请求或工作台类型会关闭原请求上的引导，并取消尚未出现的旧引导，不能让聚光区域继续指向已离开的工作台。操作锁定打断已显示的引导时，不将它记为已完成，也不在同一次访问中反复自动弹出；尚未显示的引导可以在锁定解除后继续等待首次出现。

首次使用状态按工作台类型和引导版本保存在客户端本地存储中，不属于反馈草稿、服务端请求或跨设备同步合同。只有需要再次介绍新的交互方式时才升级对应引导版本。存储不可用不应阻止使用工作台。

## 边界与维护

引导配置负责步骤顺序、说明文案和定位目标；公共聚光组件负责遮罩、定位、前后导航、关闭及键盘操作；工作台入口负责首次显示和重看。文稿审阅的引导直接定位原稿视图中的段落、批注入口和删除按钮，无需切换视图。定位使用明确的界面标记，不能依赖文字内容猜测按钮，也不能为了演示而调用业务操作。

网页引导解释浏览／元素选择、连接状态、页面内批注、集中回看及提交；未连接桥接时仍可了解截图和整体反馈的替代方式。终端引导解释工作目录、主动启动／停止／重开、全屏和样式、输出引用及提交时收尾。步骤定位首屏已有的容器或入口，不要求用户先创建批注、启动 PTY 或选中输出。

视觉反馈引导解释绘图工具与样式、撤销／重做、固定背景画布、缩放与全屏、标注意见及合成 PNG 提交。差异评审引导解释文件切换、修改前后行号、同侧同块的行范围选择与整块批注、集中回看及统一提交。两类各有五步，空草稿也有全部定位区域；首次引导无需先绘制标注或创建批注。

新增步骤时，应同时检查窄窗口、滚动容器、目标尚未出现或已隐藏的情况。缺失目标不应导致崩溃或将另一请求的元素当作目标；引导结束后恢复正常操作。

验收包括：六类首次出现分别记录、等待异步视图、跳过后不重复、手动重看、上一步与下一步、键盘关闭、只读和锁定状态、切换请求，以及整个过程不修改草稿或启动业务操作。
