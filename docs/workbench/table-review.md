# 表格审阅工作台

`table_review` v1 用于审阅固定的二维表格：按行列定位单元格，对原值提出改值建议或填写批注。表格来自本轮请求的快照；结果交给 Agent 处理源文件。

## 固定输入

Agent 先读取 `describe_workbench` 的 schema，再提供 `title`、`source_version`、`columns` 和 `rows`。列包含稳定 `id` 与可见 `label`；行包含稳定 `id` 和按列顺序排列的 `cells`。每个值都是字符串，包括数字、日期、空字符串以及公式文本。工作台显示这些原值，不执行公式。

```json
{
  "type": "table_review", "version": 1,
  "data": {
    "title": "工作台引导配置清单", "source_version": "repository-guides-2026-10-03",
    "columns": [{ "id": "type", "label": "工作台类型" }, { "id": "guide", "label": "引导版本" }],
    "rows": [{ "id": "diff-review", "cells": ["diff_review", "2"] }]
  }
}
```

列数 1–100，行数 1–1000，单元格总数最多 20000。列和行的 ID 分别唯一，匹配 `^[a-z0-9][a-z0-9_-]{0,63}$`；每行的值数严格等于列数。单个原值最多 4000 个 Unicode 标量，所有原值合计最多 500000 个。标题、源版本、列名必须含可见文本。具体边界以 schema 和运行时校验为准。

## 定位与改值

网格保留列标题与固定行号。点击单元格选中，方向键在行列间移动，Enter 或 F2 开始编辑建议，Enter 保存，Shift+Enter 在编辑值中换行，Escape 取消本次编辑。横纵滚动查看其他位置，大表格只渲染当前行窗口；从建议或批注列表选择位置会显示相应单元格。字母与行号用于显示，持久坐标使用 `row_id/column_id`。

建议保存为 `{row_id, column_id, value}`，同一单元格最多一份。原值与建议值在侧栏对照；撤回后重新显示原值。建议值可以为空字符串，表示建议清空。与原值相同的建议可以暂存草稿，提交前需改为不同值或撤回。单条建议最多 4000 个 Unicode 标量，建议值合计最多 500000 个。

## 批注、语音与引导

批注保存为 `{id, row_id, column_id, body}`，最多 500 条。草稿允许空意见，提交时已有批注必须填写可见意见，单条最多 4000 个 Unicode 标量。侧栏批注使用共享输入框，支持语音、文本整理与附件；附件引用沿用现有 Markdown 字段机制。

“语音批注”会先把空批注及稳定单元格身份加入当前请求草稿，再开始录音；初始没有工作台状态时也能接收第一笔语音。“语音建议”首次建立空的建议字段，使第一笔识别内容成为替代值；已有建议继续接收追加文本。原值始终另行显示，必要时检查并整理识别结果。建议值按字面文本编辑，其中的 Markdown 或 `attachment://` 字样不会被当作附件引用解析；附件仅放在批注或反馈正文中。

首次进入可编辑表格审阅时显示五步引导：网格、建议改值、批注、草稿与全屏、统一提交。完成或跳过后不再自动重复，标题旁的使用引导（Show guide）可以重看。引导本身不会创建建议或批注。公共行为见[首次使用引导](onboarding.md)。网格与侧栏交互参考 [Google Sheets 批注](https://support.google.com/docs/answer/65129?hl=en)和[键盘快捷键](https://support.google.com/docs/answer/181110?hl=en)，仅采用本工作台需要的操作。

## 提交与恢复

普通视图和全屏页签继续同一份 host 草稿。切换请求或重新打开可恢复建议和批注；历史保留相同原始快照与意见，只允许查看和定位。

结果为 `{source_version, changes, comments}`。运行时根据原始快照验证坐标、重复建议、长度及完整性；提交不会修改磁盘上的表格。允许只写反馈正文中的整体说明并返回空列表，也允许只提交有效建议或批注；没有任何人类输入时不能提交。审批结论与后续处理由 Agent 或外部流程编排。
