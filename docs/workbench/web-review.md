# 网页评审

`web_review` v1 用于评审 Agent 正在开发的真实网页。工作台在固定尺寸的 iframe 中打开页面；用户可正常浏览、切换元素选择，在工作台底部的浮动批注框中填写元素意见，再在评审记录中集中回看。整个请求仍复用草稿、语音、附件、提交和 Agent 续接。

## 页面接入

页面必须允许 RambleDesk 嵌入。`X-Frame-Options` 或 `Content-Security-Policy: frame-ancestors` 禁止嵌入时，客户端无法绕过浏览器限制。HTTPS Web Access 也遵循浏览器的混合内容限制。

跨源 iframe 不能由客户端直接读取 DOM。Agent 在待评审开发页中加载随应用分发的 `rambledesk-web-review.js`，页面和工作台通过限定来源、窗口和会话的 `postMessage` 协作。脚本负责悬停高亮、阻止选择模式中的原点击、生成元素信息、显示编号及滚动定位；浏览模式保留页面自己的交互。

Agent 可从当前 Local Integration Server 的 `GET /web-review/bridge.js` 下载脚本，放入待评审项目的公开静态目录，再加载项目自己的副本，例如：

```html
<script src="/rambledesk-web-review.js" defer></script>
```

使用正在运行的服务地址与端口，不能假设固定端口。该路径公开的是无凭证、无反馈数据的静态代码，反馈 API 的认证规则保持原样。自行托管也避免第三方脚本地址被开发页面的 `script-src` 拒绝。同源页面可由工作台安装同一脚本；页面 CSP 仍可能阻止安装。

未连接桥接脚本时，界面明确说明仅可预览，元素选择按钮不可用。可打开原页面体验，在整体反馈中留下意见或附件。首版不支持选择跨源子 iframe 内部元素，也不为第三方页面代理 HTML、绕过 CSP 或注入远程可执行代码。

## 输入与结果

通过 `describe_workbench({type:"web_review"})` 查询完整 schema。示例输入：

```json
{
  "type": "web_review",
  "version": 1,
  "data": {
    "title": "首页改版",
    "url": "http://localhost:5173/",
    "source_version": "homepage-v1",
    "viewport": { "width": 1280, "height": 800 }
  }
}
```

输入属于不可变请求。URL 仅允许不含凭证、反斜线、空白或控制字符的 HTTP(S) 地址，最多 8192 个 Unicode 标量；标题最多 200、来源版本最多 128 个标量。视口以 CSS px 表示，宽度 240–7680，高度 200–4320。

草稿状态为 `{type:"web_review", annotations:[...]}`。每条意见保存：

- 稳定 `id` 与 `body`；正文最多 4000 个标量，至多 500 条意见。
- 当时的 `page_url` 和 `viewport`，可不同于请求入口地址和初始视口。
- `element.selector`、`tag_name`、`text` 与 `rect`。矩形使用整数 CSS px、相对于当时文档的坐标；selector 与原文摘要只是定位线索。
- 可选 `screenshot_attachment_id`。截图、图片和文件仍使用共享附件链路，批注正文中的 Markdown 附件引用可由编辑组件展示为文件标签。

服务端按同一个冻结草稿验证、发布 `{source_version, annotations}`；来源版本由原请求确定。元素意见从 `feedback_package.manifest.workbench.result` 读取，整体感受从反馈正文读取，附件从反馈包读取。没有结构化意见时可以只提交整体正文；有空白或无效意见时不能靠整体正文跳过验证。选中元素后产生的未完成意见可保存，提交前需要填写或删除。

页面 DOM、登录状态和交互不会作为草稿恢复；已记录的 URL、视口、元素信息和意见独立保存。刷新或改版后，定位失败会明确提示，不能把意见自动挂到另一个元素。动态页面的 selector 不是跨版本身份，`source_version` 也不是服务器已保存该网页的声明。需要原始视觉证据时，用户添加截图附件。

## 布局与输入

网页请求默认在普通工作台中打开，保留任务说明、反馈正文和左侧会话导航。全屏评审按钮位于网页工具栏中，紧邻“选择元素”；点击后在会话列表右侧打开独立的评审页签，为网页提供较宽的工作区。左侧会话列表始终可操作。用户可以在普通工作台、评审页签和其他会话之间切换，也可以关闭评审页签回到普通工作台。

较窄窗口中，普通工作台的网页与反馈区上下排列，工作区可以纵向滚动，网页不会被任务说明栏的高度上限压缩掉。独立评审页签仍受工作区边界约束，不能覆盖应用标题栏或会话导航。

同一请求的普通工作台与评审页签共用草稿和网页运行状态。页签往返及关闭评审页签不会清空未完成意见、重置网页滚动或关闭网页自己的临时弹窗，也不改变 iframe 视口尺寸。网页尺寸由明确的桌面／移动视口切换改变；显示评审记录或整体反馈时，面板覆盖在评审画布上，不挤压网页触发响应式断点。较小工作区可以滚动画布查看完整宽屏页面。

桌面和手机视口按钮只显示设备图标，通过 tooltip 和可访问名称说明用途；工具栏不显示预设尺寸或当前宽高。手机视口固定为 390 × 844 CSS px，在评审区域水平居中，不随工作区宽度拉伸。尺寸数值用于视口验证和捕获数据解释。

选中元素后，批注框固定在当前工作台底部居中，采用固定尺寸；选中元素的位置、网页滚动和批注内容长度不会让它移动或扩张。工作区较窄或较矮时，批注框按可用空间限制宽高，长正文在框内滚动。网页上的元素高亮和编号仍随元素位置更新，点击编号或评审记录可以打开相应意见。

浮动批注卡只显示“批注 N”标题和批注意见框，保留删除、收起及输入工具。元素原文、页面 URL、标签名、选择器、矩形和视口等捕获信息不在浮动卡中展示，仍随意见完整保存；已结束请求的历史卡可以显示这些信息。

元素批注复用 `WorkbenchTextField`。`web_review_annotation` 输入目标固定请求和批注 ID；语音、粘贴、截图、文件采集及整理共享请求会话，不能随焦点或布局切换转移已开始的输入。删除批注后迟到写入被拒绝并保留待处理内容。整体正文和所有批注在同一 revision/CAS 下保存，批注不进入正文撤销历史。

已结束请求只显示捕获上下文与意见，不加载可操作网页。工作台不设执行批准、自动应用意见、多人线程或解决状态；Agent 根据提交结果继续开发，再评审时创建新请求。

## 验证

开发服务器的 `/?preview=fixtures&workspace=web_review` 在完整 App 中提供网页请求，可体验真实会话导航、普通工作台和独立评审页签。`/workbenches.html?type=web_review` 提供组件预览和完整 App 的入口；这些预览的草稿仅保存在各页内存。组件预览的 `?voice=1` 可验证共享模拟语音，不代表真实设备验收。

自动化覆盖输入与来源限制、消息来源/会话、元素选择、滚动定位、独立批注和总体正文、语音/附件写回、草稿恢复及 CAS、终态只读和结构化反馈包。App 集成测试覆盖默认普通布局、导航保留、同请求页签切换与关闭时共用编辑器、草稿与元素上下文；导航测试覆盖保存失败、跨会话加载和关闭尚未激活页签后迟到结果失效。手工体验可重点检查：

- 首次打开网页请求进入普通工作台；全屏评审按钮位于网页工具栏“选择元素”旁；打开评审页签后，会话列表仍可切换会话，再返回原请求继续评审。
- 普通工作台与评审页签往返、关闭并重新打开评审页签时，未完成批注、整体正文、网页滚动和网页临时弹窗保留；每个请求只有自己的意见和页面状态。
- 选择页面顶部、底部及不同横向位置的元素，批注框始终位于工作台底部居中；滚动网页不移动批注框，长批注在框内滚动，窄屏下宽高受可用空间限制。
- 浮动卡显示“批注 N”和意见输入框，删除、收起及输入工具仍可用；捕获信息在提交结果与终态历史卡中保留。
- 开关评审记录、整体反馈和批注框不改变网页视口；桌面／移动视口只有在主动切换时改变。
- 设备按钮只有图标与 tooltip，没有预设数字或当前尺寸文字；手机画布固定为 390 × 844 CSS px 并水平居中，普通／评审页签切换不改变它。

真实 Desktop WebView、站点登录、网站嵌入策略和设备截图仍需在相应环境验证。

2026-09-30 在 Windows 上使用 Chromium 151.0.7922.34 完成完整 App 浏览器回归：1680、1280、1100、900 和 390 px 窗口默认进入普通工作台；同请求打开、返回和关闭评审页签保留同一 iframe、正文编辑器、网页弹窗与批注。左侧会话列表可实际切换到另一个会话，再返回保存的网页意见。底部批注为 480 × 320 px，小工作区限制尺寸；网页滚动不移动批注，长文在卡片内部滚动。打开整体反馈保持 1280 × 800 网页视口，未出现页面异常。

同日补充验证本轮简化：1680、1100 和 390 px 窗口的全屏按钮紧邻选择元素；视口按钮没有数字文字。390 × 844 手机画布在宽工作区居中，在 366 px 工作区初始横向滚动 12 px 以居中可见区域，两侧仍可滚动查看。批注卡只有“批注 N”标题和意见框，不展示捕获的元素信息；长正文在意见框内滚动，卡片保持固定高度。普通／评审页签往返保留同一 iframe、视口及意见，未出现页面异常。

此前浏览器夹具还验证了提交保留元素意见与总体正文、提交后移除 live iframe、390 × 844 页面视口、长只读批注，以及独立两个 origin 的 bridge 选择、编号点击、浏览交互、SPA URL 和文档滚动坐标。这些结果不替代原生 WebView 或真实手机验收。
