# 开放问题清单（头脑风暴）

状态：**讨论稿**。用途：动手前把可能遇到的问题列全，逐条标记"需要现在定 / 可以边做边定 / 暂不考虑"。
本文不承诺结论，只承诺**问题不漏**。

标记：**P0** = 现在就要有答案；**P1** = 动手前要有方向；**P2** = 可以边做边定；**P3** = 暂不考虑。

## G. 反模式（明确不要做的）

- 给每个工作台复制编辑器、采集管线、草稿或提交实现。
- 把界面结构变成协议（Agent 直接发 UI schema）。
- 用工具数量表达工作台类型。
- 把 Markdown 当成结构化结果的真源，或反过来把投影当事实。
- 为抽象提前造 SDK、插件市场或动态加载。
- 在没有第二个真实工作台之前冻结接口。
