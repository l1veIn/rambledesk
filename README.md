# RambleDesk

面向 agent 的体验式反馈工作台（User_0 工作流）。

Agent 通过本地 MCP 下发结构化请求；人类按清单真实使用、语音 ramble、配截图；反馈以带图 Markdown 文件夹回传，同一会话继续迭代。

## 一句话定位

> Agent 呼叫你做真实使用反馈，你用 ramble 交回图文结果。
