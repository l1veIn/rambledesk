# RambleDesk

面向 Agent 的本地体验式反馈工作台。

Agent 通过本地 MCP 下发结构化请求；人类按清单真实使用、自由 ramble、配截图；
反馈以带图 Markdown package 回传，Agent 在原任务中继续迭代。

## 一句话定位

> Agent 呼叫你做真实使用反馈，你用 ramble 交回图文结果。
