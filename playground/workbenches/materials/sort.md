# 拖动排序体验

你正在为一个 CLI 工具排功能优先级。列表从上到下表示优先级从高到低；保留初始顺序也可以提交。排序理由可以写在右侧正文中。

1. 将“配置文件”拖到第一位，再把任意条目拖到中间或末尾，检查编号与顺序是否同步。
2. 用 Tab 聚焦拖动手柄，按空格或回车开始，方向键移动，再按空格或回车完成；检查键盘排序与拖动结果一致。
3. 编辑“配置文件”的文字；清空名称时仍应保存草稿，但不能提交。补回名称后继续排序。
4. 删除一项，在已删除列表中恢复，检查编辑过的文字保留、恢复的条目在末尾。也可以删除所有条目，明确提交空列表。
5. 切换请求再返回，检查排序、改过的文字、已删除条目与补充正文的草稿恢复。
6. 检查排序工作台没有全屏入口、没有上下移动按钮；在普通工作台中继续编辑，左侧会话列表应保持可用。
7. 不填写补充正文直接提交，检查只读历史中的顺序、文字和已删除项目与最终提交一致，条目无法继续编辑、删除、恢复或移动。

反馈请说明拖动是否顺手、放置位置是否清楚，以及是否有草稿丢失或意外跳动。触屏设备上的拖动未实际体验时请标为“未验证”。
