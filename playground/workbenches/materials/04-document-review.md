# 文档审阅

原稿是一份特意留有问题的 Markdown 视频脚本。请尝试：

1. 浏览标题、列表、表格、引用和代码块，确认它们按文档结构呈现，而不是一组独立的段落输入框。原始 Markdown 始终只读。
2. 选中开场里的“你好😀”，通过“批注”在原文附近填写意见，用于检查中文与 emoji 锚点。点击“完成”或按 Ctrl/Cmd+Enter，确认返回原文继续阅读而没有提交整轮；再选同段另一处文字创建另一条批注，确认各自的引用和意见独立。
3. 选中演示段里夸大的“自动理解……最好的决定”一句，添加修改建议并写出替代文字，理由可选。再编辑原意见，确认已有建议措辞和引用不变。另建一条建议，保持预填原文且不填理由，确认不能直接“完成”，Escape 会移除这条未触碰的新建议；已改动的建议收起后仍应保留。
4. 从一个段落的末尾选到下一段开头，添加跨段批注；对列表、表格或格式化文字作批注，检查引用对应原始 Markdown，而非猜测渲染后的偏移。对不支持精确映射的内容如实记录限制，不自行改稿凑锚点。
5. 使用全文批注入口写一条整体意见，确认不错误绑定到某个段落。原文内其他批注仍保留。
6. 选中冗余句并添加修改建议，将建议措辞清空，表达删除建议；也试一次不填写理由。原文不能直接消失，也不再依赖旧“删除段落”标记。
7. 从原文高亮处回访批注，续写后按 Escape，确认返回原文且内容保留；另建一条空白普通批注，Escape 也应保留它，最后提交前须补全或明确删除。在宽窄布局间切换，意见、建议、附件引用应保留。尝试删除有内容的批注，先取消或在确认框按 Escape，再确认删除；空措辞的删除建议也需确认。局部“完成”不是保存成功回执，等待草稿保存后再离开和返回，检查全部批注和范围。
8. 选择“原稿可用”或“需要修改”，确认所有普通批注都已填写意见或删除，再提交。修改建议可以不填写理由，空替换文本仍表示删除建议。

有语音能力时，在第 8 步提交前额外检查：

- 点击批注意见顶部工具栏的麦克风，说一条意见；再次点同框麦克风会暂停。继续录音时点击另一条批注或“建议措辞”的麦克风，录音应持续，等下一段再说，旧段结果仍回到原字段。
- 右下角只显示左侧 Rambelle 大头像、右侧状态气泡和有待整理内容时的整理按钮；录音暂停和切换位置都使用输入框顶部的麦克风。
- 返回补充正文说一句，再回到批注说一句；录音不应因切换目标而重启，原稿始终不变。
- 暂停后从批注或补充说明的麦克风继续录音，已写入的内容不重复。
- 用批注顶部工具栏粘贴普通文字，文字应进入该字段且不计入语音整理。导入图片、截图或文件后，检查对应批注意见或建议措辞旁出现可预览的附件标签；附件仍属于该请求，采集期间换框不能改变本次归属。
- 截图选区尚未完成、附件保存中或有待确认语音时尝试提交：应等待已接收操作完成，或给出明确处理提示。

已配置整理能力时，在批注意见、建议措辞和补充说明至少两个位置录入语音，并额外键入和粘贴各一句。点击右下角 Rambelle 区域的“整理 N 段语音”，检查每段保留来源并回到原位置，键入和粘贴文字不被整理，原稿不变。检查无待整理内容时隐藏空按钮、整理中显示状态、成功后按钮收起、失败可重试。整理期间切换批注不应改变回填位置；可选地修改或删除一条正在整理的批注，迟到结果不能重建或覆盖它。提交区的“整理补充说明”只处理正文，不代替本项体验。

没有麦克风或未配置识别能力时，记录语音相关项为“未验证”，继续键入完成本轮。

你可以按自己的判断操作。Agent 只核对实际提交内容，未尝试的功能会记为未验证；原稿始终不应被批注或建议直接改写。
