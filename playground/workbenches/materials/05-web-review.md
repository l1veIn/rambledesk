# 网页评审

本次评审的是 Atelier 示例网页。页面里的创作、套餐和邮箱弹窗都是体验材料，不需要填写真实资料。打开请求时应先进入普通工作台，左侧会话列表保持可操作。网页应显示“元素选择已连接”；如果一直加载、页面不可用或仅可预览，请在整体意见里记录实际提示，不把无法选择元素记为通过。

请在提交前尝试：

1. **浏览网页。** 保持“浏览”模式，点击首页“开始创作”，确认出现“欢迎加入 Atelier。”弹窗，再用弹窗中的关闭按钮关闭。点击导航“方案”或在网页区域滚动到“准备开始了吗？”；网页应能正常滚动和交互。回到首页，准备点评。
2. **底部固定批注。** 点击“选择元素”，选中“开始创作”按钮（`review-signup`），填写一条具体意见，例如按钮措辞或视觉层级。此时应该在工作台底部居中打开固定尺寸的批注框，而不会触发网页的欢迎弹窗；保存后的元素应有编号。浮动卡只显示“批注 N”标题和意见框，删除、收起及输入工具仍可用，不展示元素原文、页面地址、选择器或视口等捕获信息。再选中“让好想法成为好作品。”标题（`review-heading`），添加第二条意见。两次选择的元素位置不同，批注框的位置和尺寸应保持稳定；滚动网页时它也不跟着元素走。试着填写多行意见，内容应在框内滚动，卡片不会随正文增高。收起并重新选择同一元素，确认继续编辑原批注，内容保留，没有多出一条重复记录。
3. **整体意见与固定视口。** 在普通工作台右侧的整体反馈中写一句针对整页的意见，再开关“评审记录”。进入独立评审页签后，也试着开关“整体意见与提交”浮层。检查网页没有因这些面板打开而重新排版：页面可视范围与布局保持稳定，按钮、标题和已有批注仍对应原元素。元素意见应留在自己的批注中，整体意见应留在反馈正文中；工具栏不显示当前宽高数字。
4. **独立评审页签与会话导航。** 在批注中留一段尚未写完的文字，点击网页工具栏中紧邻“选择元素”的全屏评审按钮；入口应位于网页工具栏内。应打开会话列表右侧的独立评审页签，左侧会话列表仍可点击。通过工作区页签切回普通工作台，再回评审页签，检查未完成文字、选中的批注和网页滚动位置保留。关闭评审页签，应回到普通工作台并可继续编辑；再次用同一工具栏入口打开评审页签，意见仍在。再收起批注、切回“浏览”，打开网页的欢迎弹窗，重复普通/评审页签往返与关闭操作，确认网页弹窗仍然存在，页面没有重新加载。通过左侧会话列表切到另一个已有会话，再返回原请求，检查可以继续当前评审且没有把意见写到其他请求；没有其他会话时把这一项记为“未验证”。关闭欢迎弹窗后继续评审。如果窗口本身较窄，也检查网页工具栏能换行，底部批注框的宽高限制在工作区内、内容可滚动，导航和批注工具仍可操作。
5. **桌面与移动视口。** 桌面和手机按钮应只显示设备图标，悬停或聚焦可辨认 tooltip；按钮旁不显示预设数字或当前尺寸文字。点击桌面图标，再点击手机图标，检查页面按所选设备布局变化。手机画布固定为 `390 × 844` CSS px 并在评审区域水平居中，不随工作区拉宽；可以在较宽窗口和独立评审页签中检查居中效果。在移动视口给标题补充一条关于窄屏的意见，再切回桌面。两种视口的意见应各自保留；从“评审记录”打开移动批注时，应回到它记录的移动视口，打开桌面批注时应回到桌面视口。浮动面板仍不应改变所选视口的宽高。桌面 `1440 × 900`、手机 `390 × 844` 作为捕获数据与页面尺寸的验收值，提交后由 Agent 核对，不要求界面显示这些数值。
6. **回访滚动位置与 SPA 页面。** 在桌面视口切回“浏览”，滚动到方案区域（`#plans`），点击“查看团队方案”，欢迎弹窗应出现。关闭网页弹窗，切到“选择元素”，给“查看团队方案”按钮留一条意见，并在整体反馈中记录这是切换方案页面后的批注；其保存的页面地址应以 `#team-plan` 结尾，提交后由 Agent 核对。再从“评审记录”打开此前的首页标题批注，应回到该批注记录的页面并定位标题，原意见保留。收起后再打开当前页同一批注，确认可以继续写，不会再次创建批注。再从记录来回打开首页与方案批注，观察是否正确回到各自的页面、元素和视口。
7. **空白批注与删除取消。** 选择一个尚未点评的元素，例如“留住每个灵感”标题，创建批注后保持正文空白。即使整体意见已填写，提交也应被阻止，并提示补全或删除空白批注；不要只为了让提交按钮可用而跳过检查。从评审记录打开这条空白批注并删除，应可直接移除。另选一条已有内容的批注，点击删除后先取消或按 Escape，确认意见和附件保留；确实想移除时再删除并确认。检查其余批注仍在。
8. **刷新与草稿保存。** 可选：等待草稿保存后点击网页工具栏的刷新按钮（环形箭头），确认网页重新连接、批注和整体正文没有丢失，能从记录重新定位并续写。需要验证持久化时，可重开应用或重新载入本请求，检查已保存的页面信息、意见和视口记录。主动刷新网页、重开应用或重新载入请求可能重置网页本身的临时弹窗、滚动和 SPA 状态；这与第 4 步普通/评审页签往返时保留现场是两项不同检查。
9. **提交。** 确认所有保留的批注都有意见，关闭不需要的弹窗，通过普通工作台右侧的提交区域，或评审页签中的“整体意见与提交”提交。网页评审没有单独的“原稿可用／需要修改”结论；元素批注与整体正文一起提交。若希望只提交整页意见，可删除全部元素批注后提交非空正文，不需要额外创建元素批注。
10. **提交后只读。** 提交完成后查看原请求；如果应用已续接到汇总，可从原请求记录返回查看。实时网页预览应退出，已提交的批注、元素文字、页面地址、选择器和视口信息应可完整阅读；有多条记录时能滚动看到最后一条。批注不能再修改或删除，附件仍可预览。不能把还在加载、仍可选取网页元素的界面当成只读展示通过。

有共享输入能力时，在第 9 步提交前额外检查：

- 在元素批注意见顶部点击麦克风，说一条意见；再次点同框麦克风暂停。继续录音后打开整体意见浮层，点击正文麦克风切换后续输入，再回到另一条元素批注继续说；已开始的语音仍应回到原位置。
- 从批注工具栏粘贴普通文字，文字应进入该条批注。尝试截图、图片粘贴或文件附件，检查可预览的附件标签保留在该字段；采集或选择文件期间换框不能改变本次归属。
- 已配置整理能力时，在批注与整体正文至少两个位置各录一段，并另行键入、粘贴各一句。从右下角 Rambelle 区域执行“整理 N 段语音”，检查语音各自原位更新，键入和普通粘贴文字保持原样；切换评审记录或整体意见浮层不改变回填位置。没有待整理内容时不保留空整理按钮，失败后可以重试。
- 可选：在异步语音或整理尚未完成时删除一条批注，迟到结果不能重建它，也不能改写另一条元素意见。截图尚未完成、附件保存中或有待确认语音时尝试提交，应等待已接收操作完成或给出明确提示。

没有识别、整理、截图或粘贴能力时，对应项记为“未验证”，继续键入完成本场景。没有真正执行的会话列表切换、普通/评审页签往返与关闭、网页工具栏入口位置、精简批注卡、图标按钮与 tooltip、手机画布居中、底部批注位置及内部滚动、刷新、重开、窄屏操作、SPA 回访或只读查看也记为未验证；最终结果中有批注，并不能证明这些交互都已通过。请在整体意见里写出实际尝试的操作和遇到的问题，Agent 只核对真实提交内容。
