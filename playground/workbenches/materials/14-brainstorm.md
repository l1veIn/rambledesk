# 头脑风暴体验：第一次有用的反馈

讨论一个具体问题：怎样让新用户完成第一次有用的反馈？看板中的想法都是讨论起点，你可以修改、补充或暂放，不必接受 Agent 的原话。

1. 改写一张已有卡片的标题和正文，补充一张自己的卡片。可用卡片正文的语音或附件工具；未配置的能力记为未验证。
2. 新建或改名一个分组，移动卡片。切换发散、整理、聚焦，检查修改是否保留；它们不要求按固定顺序完成。
3. 选中两张方向卡，暂放一张不想继续讨论的卡。暂放不会删除内容、暂放卡不能同时选中；可恢复后继续修改。
4. 切换到另一个请求再返回，确认卡片、分组、选择、暂放项和整体意见还在。空标题可保存草稿，但应阻止最终提交；补回后继续。
5. 选择下一步：再探索不要求选卡；展开或“按选中方向继续原任务”至少选一张；组合至少选两张。可填写具体要求，最后统一提交。选择本身不会立即调用 Agent。

愿意体验多轮时，可在第一轮选择展开或组合。Agent 收到真实结果后会追加少量新卡，不能重新抄写或覆盖旧卡。第二轮重点检查：改过的文字、人新增卡、分组、选择与暂放状态是否保留；已有卡片附件是否仍能打开；新卡是否明确关联到你上轮选中的方向。新一轮的下一步选择和补充指令应为空，上一轮整体意见仍留在历史中，不冒充新的输入。

已经有足够方向时，选择“按选中方向继续原任务”结束本场景的看板讨论。这个 Playground 中的原任务是记录体验与结果并继续汇总，不是自动修改产品。若不体验第二轮，仍可结束本场景，多轮继承如实记为未验证。

请报告你是否理解每张卡的来源、当前选择与下一步，以及有没有改字丢失、暂放卡意外恢复或反馈重复发送。已提交历史应只读；实际操作与结构化结果要分别核对，不能从预览或一份 JSON 推断全部通过。
