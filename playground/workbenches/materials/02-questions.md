# 2/4 · 逐项问答

1. 先只回答第一题，观察全部答完前能否提交。
2. 第一题试一次“自定义回答”；第二题应只有固定选项。
3. 回到已答的题修改一次，再进入总览检查答案。
4. 可选：等待保存后离开再回来，检查答案仍在。
5. 补充正文留空，回答全部题目后提交。

有语音能力时，选择第一题的自定义回答，点击答案顶部工具栏的麦克风。右下角左侧是 Rambelle 大头像，右侧气泡应显示录音状态。再次点同框麦克风可暂停；重新开始说话后，点击补充说明的麦克风，录音应持续。等待转写：已开始的一段仍应进入原题，下一段进入补充说明。返回该题，可以继续说或键入，不会自动跳到下一题。

已配置整理能力时，在第一题自定义回答和补充说明各录一段，再手动键入和粘贴各一句。检查两处的语音来源标识与 Rambelle 区域“整理 N 段语音”的计数，点击后各段应原位更新，键入和粘贴文字不变。没有待整理语音时不显示空按钮；整理中显示状态，成功后按钮收起，失败可重试。整理进行中可以切到另一题；目标切换不应重定向结果。可选：在整理期间手动修改一个语音片段，或将该题改选固定选项，返回的整理结果不应覆盖你的新内容。

可选：从自定义回答顶部工具栏添加截图或文件，检查文件标签显示在该题的输入框旁并可预览。打开文件选择器或开始截图后切换输入位置，本次附件仍应留在原题。粘贴普通文字应进入答案，不增加语音整理计数。

可选：说话后改选固定选项或点击“清除回答”，再等待识别结果。固定选择不应被迟到转写覆盖；处理保留下来的待确认语音后再提交。语音和恢复未实际体验时请记为“未验证”。

Agent 会按问题 ID 读取结构化答案。选择或自定义内容由你决定，没有标准答案。
