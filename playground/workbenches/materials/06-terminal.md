# 终端工作台体验

点击「开始试用」后，从下面复制命令到终端，按回车运行；你也可以修改命令或自由输入。示例不需要安装依赖，不访问网络或写文件。

查看帮助，检查中文与彩色输出：

~~~sh
node ./materials/terminal-demo.mjs --help
~~~

交互式问候，按提示输入名字：

~~~sh
node ./materials/terminal-demo.mjs greet
~~~

选择布局，用方向键选择、回车确认，也可以用 Ctrl+C 退出：

~~~sh
node ./materials/terminal-demo.mjs choose
~~~

查看错误与处理提示：

~~~sh
node ./materials/terminal-demo.mjs error
~~~

1. 复制帮助命令，按回车。检查帮助、中文与彩色输出是否清楚。
2. 运行问候命令，输入名字并确认；记录交互提示是否自然。
3. 运行布局选择，尝试方向键、回车；再运行一次，用 Ctrl+C 退出。退出当前 CLI 后仍应能继续使用 shell。
4. 运行错误命令，判断错误与处理提示是否有帮助。CLI 的错误退出码不代表反馈不合格。
5. 鼠标选中一段输出，用「引用选中输出」将它放进右侧反馈正文，继续写意见。也可以使用正文原有的语音、截图、粘贴和附件工具。
6. 从终端工具栏打开全屏新页签。左侧会话列表始终可用；普通/全屏页签往返与关闭全屏页签应保留同一终端进程、输出及反馈正文。切到其他请求后返回也应能重新连接。
7. 点击「停止终端」，再点击「重新启动终端」，复制帮助命令继续试用。也可以输入 `exit` 结束 shell，再重新启动。各轮会话的记录都应保留；停止或退出后的重开由你主动触发。
8. 写下整体感受后提交。提交前会停止终端并收尾输出；提交后只能查看已保存记录，不应继续运行命令。

记录会话起始目录、shell、终端尺寸、转录、最后可见画面与 shell 会话终态。原始按键不记入反馈；命令通常可从 shell 回显查看，CLI 关闭回显的输入不会被额外捕获。长输出达到上限时要显示截断提示，不能宣称完整保留。应用重启后保留保存记录，旧进程不自动复活。

未实际体验的重连、重启、手机触控、语音、附件与跨平台行为请记为未验证。
