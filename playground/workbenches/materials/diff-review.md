# 差异评审体验

这轮只评审请求中保存的 diff，不修改源文件，也不规定团队审批步骤。

1. 查看 `src/help.ts`，分别针对删除行和新增行批注，确认修改前后行号不同。
2. 选择一个行范围并留言；另给整个改动块留一条意见。可以使用批注输入框的语音和附件工具，未体验的设备能力记为“未验证”。
3. 切换到 `config.json`，检查修改位置，添加意见；从批注列表回到对应文件和行。
4. 修改和删除批注，切换请求或重开应用，检查恢复；全屏往返应继续同一份草稿。
5. 在右侧补充整体意见并提交。也可以单独开一轮仅提交整体说明，检查空批注列表不会强制要求审批结论。

Agent 核对 `source_version`、稳定文件 ID、零基 `hunk_index`、`old/new` 侧和实际行范围。整块批注的 `start_line/end_line` 同时为 null；不能把 diff 视图中的显示索引当成源文件行号。批注绑定固定快照，不因磁盘文件或分支随后改变而漂移。
