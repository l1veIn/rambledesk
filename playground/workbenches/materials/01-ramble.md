# 1/6 · 自由反馈

这是一份虚构的产品体验素材：一个“随手记”工具把体验过程中的文字、语音和截图汇成反馈，提交后由 Agent 继续处理。

1. 检查正文顶部的麦克风、截图、粘贴和附件工具栏，以及右下角左侧的 Rambelle 大头像和右侧状态气泡。在右侧写两句话，例如“入口很清楚，但提交前想确认附件是否齐全”。
2. 修改一句，再试一次撤销/重做。
3. 可选：点击正文顶部的麦克风录一段语音，再点同一按钮暂停，检查转写和语音来源标识；从同一工具栏试一次粘贴、截图或添加文件。没有设备或权限可以跳过。
4. 可选：等待“已保存”，离开本请求再返回，检查正文仍在。若测试重启，回到同一个会话继续。
5. 提交反馈。Agent 会读取你实际写的内容，然后发起问答。

不需要按示例作答，直接写真实感受。未体验的可选功能不会算作通过。

已配置整理能力时，先键入和粘贴各一句，再点击右下角 Rambelle 区域的“整理 N 段语音”。检查口述内容原位更新，键入和粘贴的文字保持不变，已整理的语音不再计入待整理数量。没有待整理语音时不应保留空的整理按钮；处理中显示状态，成功后按钮收起，若失败应能重试。提交区域的“整理补充说明”是另一项功能，不把它算作本项通过。
