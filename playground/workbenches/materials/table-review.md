# 表格审阅体验

本轮材料是仓库中六个工作台的实际引导配置清单快照，记录配置路径、引导版本与步骤数。清单用于开发验收；提出的改值建议不会直接改动这些文件。

1. 完成或跳过首次五步引导，确认没有生成建议或批注；标题旁的使用引导（Show guide）可以重看。
2. 对照列标题与行号，用方向键移动选中单元格。按 F2 编辑一个建议，输入后按 Escape，确认取消；再次用 Enter 编辑并保存，侧栏应同时显示原值与建议值。
3. 对一个非空单元格保存空字符串，确认可以建议清空；撤回该建议后显示原值。给其他单元格保留一份不同于原值的建议。
4. 在没有批注的草稿中点击“语音批注”，确认首条批注先建立到当前单元格；语音与附件使用共享工具。无法使用的设备能力记录为“未验证”。已有批注可以修改、删除，从列表点击可回到同一个单元格。
5. 横向滚动查看较长配置路径；纵向滚动时列头保留。全屏往返、切换请求或重开应用，确认同一份建议与批注可恢复。
6. 填写已有空批注、撤回与原值相同的建议后提交。另开一轮可仅在反馈正文写整体说明；返回的 `changes/comments` 应为空，不强制审批。

Agent 核对结果的 `source_version`、稳定 `row_id/column_id`、建议替代值与批注身份。显示位置如 C1 仅用于导航，不能替代持久行列 ID。原始单元格和源文件在审阅中保持固定；已提交历史只读。
